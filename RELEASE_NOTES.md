# Fruit Archer v9.0.1

Install `FruitArcher-v9.0.1.apk` on Android 7.0 or newer. If an earlier version is installed, uninstall it first (builds are signed with a per-build debug key until signing secrets are added to the repo), so earlier progress does not carry over. To keep v9.0.0 progress, copy a backup code from Settings → Backup & restore before uninstalling.

## Changed
- The game is English only again. The Hindi and Gujarati translations and the language picker were removed, along with their fonts (the APK is slightly smaller).

Everything else is as in v9.0.0: Adventure (40 stages, 4 bosses), Daily Challenge, 5 arrow types, weekly and career missions, season track, guided training, score sharing, backup codes.

## Known limits
- Not yet tested on a physical phone; stage difficulty and coin economy have not been tuned from real play sessions.
- No online leaderboards or cloud save: the daily challenge and backup code are local only.
